# Trash-Can-3d
Low poly stylized 3D rendering of a traditional metal garbage bin. It features a ribbed cylindrical structure, a tiered lid with a handle in the middle and has some detailing at the rim. The rough geometries have been rendered in metallic grey color giving the object an industrial feel.

Sketch-fab: https://sketchfab.com/3d-models/metal-trashcan-00dcd68130cc4a919ffa9ff1a525de37
